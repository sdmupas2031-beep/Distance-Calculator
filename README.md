# Distance-Calculator

# Project Title: Distance Calculator

## Description
This program calculates the distance between two points using predefined functions built in the library

## How to run
!. Open the program file
2. Run the program
3. Enter the coordinates for the x - axis
4. Enter the coordinates for the y-axis
5. Program displays the calculated distance

## Input Needed
- x1
- x2
- y1
- y2

## Sample Output
Enter x1: 2
Enter y1: 3
Enter x2: 7
Enter y2: 8
The distance between the two points is: 7.07
